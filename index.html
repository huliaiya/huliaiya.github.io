Chromium 一键安装脚本

🚀 一键执行命令
bash — chromium.sh
$ curl -sL https://huliaiya.github.io/scripts/chromium.sh -o /tmp/chromium.sh && sudo bash /tmp/chromium.sh
💡 点击右侧按钮即可复制命令，粘贴到终端回车执行
使用步骤
1️⃣

环境准备

确保设备已安装 curl 和 sudo（手机容器请先进入 Debian/Ubuntu 环境）

2️⃣

复制命令

点击上方按钮复制一键命令，或手动选中复制

3️⃣

执行安装

粘贴到终端执行，根据提示选择 1.安装 或 2.更新（默认 1，30 秒自动确认）

4️⃣

完成验证

脚本会自动验证版本、路径、运行状态并锁定版本，防止系统更新破坏

脚本特性
🌐

智能镜像

自动检测国内/国外网络，国内走 USTC 镜像，国外走官方源

🚫

防 Snap

自动屏蔽 snap 版 chromium-browser，确保安装原生 deb 包

🔗

依赖解析

递归解析所有依赖并设置高优先级，避免依赖冲突

📊

进度显示

带进度条、旋转动画和实时状态，过程一目了然

🔄

失败重试

网络下载失败自动重试最多 3 次

🔒

版本锁定

安装完成后自动 apt-mark hold，防止系统更新破坏

注意事项

请仔细阅读

  • 此脚本仅支持 Debian / Ubuntu 系发行版
  • 需以 root 或 sudo 运行
  • 适用于：手机 proot 容器、Linux Deploy、Termux 的 proot-distro 等环境

Linux 一键换源脚本

🚀 一键执行命令
bash — change-mirrors.sh
$ curl -sL https://huliaiya.github.io/scripts/change-mirrors.sh -o /tmp/change-mirrors.sh && sudo bash /tmp/change-mirrors.sh
💡 点击右侧按钮即可复制命令，粘贴到终端回车执行
使用步骤
1️⃣

环境准备

确保设备已安装 curl 和 sudo，需以 root 或 sudo 权限运行

2️⃣

复制命令

点击上方按钮复制一键命令，或手动选中复制

3️⃣

选择配置

根据提示选择镜像类型（默认/教育网/海外）、协议（http/https）等

4️⃣

完成换源

脚本自动备份原配置、替换源、升级软件，完成后输出结果

脚本特性
🖥️

多发行版

支持 Debian/Ubuntu/CentOS/RHEL/Fedora/Arch/Alpine/Gentoo/openSUSE 等 30+ 发行版

🌐

多镜像源

内置阿里云、腾讯云、华为云、清华、中科大、浙大等 18+ 国内主流镜像

🏫

教育网支持

支持教育网镜像（清华、北大、浙大、上交、华科等），校园网用户首选

🌍

海外镜像

支持海外官方源模式，适合境外服务器使用

🔐

协议选择

支持 http / https 协议自由切换

💾

自动备份

替换前自动备份原软件源配置，随时可恢复

📦

EPEL 支持

CentOS/RHEL 可选择安装 EPEL 扩展源

⬆️

软件升级

换源完成后可选择是否一键升级全部软件包

注意事项

请仔细阅读

  • 支持大多数主流 Linux 发行版（Debian/Ubuntu/CentOS/RHEL/Fedora/Arch/Alpine/Gentoo/openSUSE 等）
  • 需以 root 或 sudo 运行
  • 脚本会自动备份原始配置，如有问题可手动恢复备份文件
