## ⚡ 为什么选择 Huli？

市面上的 Root 管理工具要么年久失修，要么功能臃肿广告遍地。Huli 从零开始设计，专为新时代的 Android 打造：

| 特性 | Huli | 传统工具 |
|------|------|----------|
| **Material You 设计** | ✅ 原生支持动态取色 | ❌ 千篇一律的老界面 |
| **液态玻璃视觉** | ✅ 实时模糊 + 半透明材质 | ❌ 死板的纯色块 |
| **应用权限管理** | ✅ 可视化 + 一键撤回 | ❌ 藏得深，操作繁琐 |
| **批量冻结/卸载** | ✅ 多选秒处理 | ❌ 一个一个手动点 |
| **启动项管理** | ✅ 开机自启精确控制 | ❌ 功能缺失或需付费 |
| **后台唤醒拦截** | ✅ 切断唤醒链条 | ❌ 依赖 Xposed 模块 |
| **无广告 / 无联网** | ✅ 纯本地运行 | ❌ 你懂的 |

## 🚀 核心功能

### 🔐 Root 权限管理
- 精细化授权控制，每个应用单独设置
- 权限使用历史记录，随时回溯
- 临时授权模式，用完即回收

### 📦 应用管理
- 批量卸载 / 冻结 / 解冻
- 一键禁用系统预装（告别 Bloatware）
- 查看完整应用信息：包名、版本、签名、权限列表
- 导出 APK / 分享应用

### ⚡ 性能优化
- 开机自启项管理，从源头控制
- 后台唤醒链切断，告别毒瘤全家桶
- 缓存批量清理，释放存储空间

### 🛡️ 隐私保护
- 权限使用统计与提醒
- 敏感权限一键撤回
- 应用行为审计（规划中）

### 🎨 极致体验
- 深色 / 浅色 / 跟随系统 三档主题
- 原生 Material You 动态色彩
- 液态玻璃（Liquid Glass）视觉效果
- 丝滑过渡动画，流畅到指尖

## 🎯 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| **Android 版本** | 7.0 (API 24) | 12.0+ (获取最佳视觉效果) |
| **Root 权限** | Magisk / KernelSU / APatch | 最新稳定版 |
| **存储空间** | 20MB | 50MB+ |
| **架构** | arm64-v8a | arm64-v8a + 原生中文界面 |
