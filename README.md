## 📖 关于 Huli

Huli（狐狸）是一款专为 **Android 搞机爱好者** 打造的新一代 **设备安全体检 & Root 管理工具**。

你有没有过这些担心？
- 😱 手机是不是被偷偷植入了木马？
- 🕵️ 有没有远控软件在后台偷偷上传你的照片和视频？
- 🔑 你保存的密码是不是被恶意 App 读取了？
- 📡 有没有应用在偷偷调用你的摄像头和麦克风？
- 📤 你的通讯录、短信、位置信息是不是被上传到了未知服务器？
- 💣 系统模块是不是被替换或注入了恶意代码？

**Huli 就是为了解决这些问题而生的。**

我们整合了 **VirusTotal、Hybrid Analysis、MetaDefender** 等全球顶级云端扫描引擎（70+ 杀毒引擎联合检测），配合本地的深度行为分析、权限审计、模块完整性校验、网络流量监控等技术，为你的 Android 设备提供**一站式的全面安全体检服务**。

从应用层到系统层，从权限管理到网络监控，从病毒查杀到密码安全 —— **Huli 就是你口袋里的安全专家。**

> **为什么叫 Huli？** 狐狸在东方文化中象征着机智、敏捷和灵性。我们希望这款工具能像狐狸一样，敏锐地嗅出设备中的每一丝异常，灵动地应对每一种威胁，为你的 Android 之旅保驾护航。而且「狐狸」和「Root」还有一个共同点 —— 都是为了更自由地掌控自己的领地 🦊

## 🛡️ 云端安全检测引擎

Huli 接入了全球顶级的云端安全扫描服务，为你的设备提供企业级的安全防护能力。我们深知，Root 后的设备就像打开了潘多拉的盒子，权限越大，风险也就越大。Huli 的云端检测引擎就是你设备的「电子眼」，24 小时守护你的使用安全。

> 💡 **为什么选择云端扫描？** 本地病毒库不仅占用存储空间，还需要频繁更新。而云端扫描依托全球数千台服务器的实时威胁情报库，总能识别最新的恶意软件。同时，我们只上传应用的哈希值（不是整个 APK 文件），既保护了你的隐私，又能快速获得检测结果。

### 🦠 可检测的威胁类型

#### 🔴 恶意软件类
- **木马程序检测** — 识别隐藏在正常应用中的木马、后门程序。那些伪装成「实用工具」「游戏辅助」的恶意 App，在 70+ 云端引擎面前无所遁形。
- **勒索软件检测** — 扫描具有文件加密行为的可疑应用。在你的照片和文档被加密勒索之前，提前发现并清除威胁。
- **间谍软件检测** — 发现窃取短信、通话记录、位置信息的恶意程序。你的隐私不该成为别人的商品。
- **广告软件检测** — 识别植入恶意广告 SDK 的应用。那些后台偷偷弹广告、偷流量的 App，一次性清理干净。
- **挖矿程序检测** — 检测后台偷偷运行的加密货币挖矿程序。你的手机性能不该被用来给别人挖矿。
- **银行木马检测** — 专门针对金融类 App 的木马识别。支付安全是重中之重，让每一笔交易都安心。
- **Rootkit 检测** — 扫描深度隐藏的 Rootkit 和 Bootkit，从系统底层揪出潜伏的威胁。
- **钓鱼网站检测** — 接入 Google Safe Browsing 和 urlscan.io，实时检测恶意网址和钓鱼网站。

#### 🟠 系统安全类
- **系统模块完整性校验** — 检测 `/system`、`/vendor`、`/product` 等分区的系统模块是否被篡改、替换或注入恶意代码。校验每个系统文件的哈希值，一旦发现与原厂 ROM 不一致立即报警。那些通过 Magisk 模块偷偷替换系统组件的恶意行为，再也藏不住了。
- **木马植入检测** — 深度扫描系统服务、Zygote 进程、应用进程中是否被注入了木马代码。检查 dex 文件、so 库、odex 缓存是否被 patch 或 hook。从应用层到框架层再到 Native 层，全方位排查植入威胁。
- **模块安全审计** — 扫描所有已安装的 Magisk / KernelSU 模块，检测模块脚本中是否包含恶意命令、是否修改了系统关键文件、是否在开机时执行了可疑操作。每个模块都经过安全评级，危险模块立即标记警告。

#### 🟡 网络安全类
- **远控后门扫描** — 检测设备中是否安装了 TeamViewer、向日葵、ToDesk、AnyDesk 等远控软件，以及各种开源远控工具（如 AhMyth、AndroRat、SpyNote 等）。扫描异常的后台服务、端口监听和网络连接，发现潜伏的远控后门立即切断并报警。
- **恶意上传监控** — 实时监控应用的网络行为，检测是否有应用在后台偷偷上传你的照片、视频、通讯录、短信、文件等敏感数据。通过流量大小、上传频率、目标服务器域名等多维度判断，一旦发现可疑上传立即弹窗警告，并显示具体上传了什么内容。
- **可疑域名拦截** — 对接威胁情报库，自动拦截与恶意软件、钓鱼网站、僵尸网络 C&C 服务器相关的域名和 IP。

#### 🔵 隐私安全类
- **密码安全检测** — 扫描设备中已保存的密码（如浏览器、应用中的登录凭证），检测是否存在**弱密码**（如 123456、password）、**重复密码**（多个账号使用同一个密码）、**泄露密码**（对接 Have I Been Pwned 数据库，检测你的密码是否已经在数据泄露事件中被公开）。发现问题立即提醒你修改。
- **摄像头/麦克风调用检测** — 实时监控哪些应用在使用摄像头和麦克风。当有应用在后台偷偷调用时立即闪烁警告，并记录调用时间和时长。
- **剪贴板读取监控** — 检测哪些应用在读取你的剪贴板内容。你的身份证号、银行卡号、验证码不该被无关应用看到。
- **敏感文件扫描** — 扫描设备中是否存在身份证照片、银行卡照片、私密照片等敏感文件被存放在不安全的位置，检测是否有应用可以访问到这些文件。

### 🔬 检测技术

| 检测方式 | 说明 |
|----------|------|
| **云端多引擎扫描** | 一次提交，70+ 杀毒引擎同时检测，检出率碾压任何单一杀毒软件 |
| **哈希值快速查询** | 只上传 APK 的 MD5/SHA1/SHA256 哈希值，保护隐私，秒级出结果 |
| **沙箱动态分析** | 在隔离环境中运行应用，观察其真实行为（网络请求、文件操作、权限调用等） |
| **启发式分析** | 通过行为模式识别未知的新型恶意软件，0Day 漏洞也能早发现 |
| **权限分析** | 检查应用是否申请了超出其功能所需的权限，一个手电筒 App 要位置权限？绝对有问题 |
| **签名验证** | 验证应用签名是否被篡改或替换，防止被二次打包的山寨 App 混入设备 |
| **网络行为分析** | 检测可疑的网络连接和数据上传行为，谁在偷偷上传你的通讯录？ |
| **威胁情报匹配** | 依托全球实时威胁情报库，第一时间识别最新爆发的恶意软件 |
| **系统文件完整性校验** | 比对原厂 ROM 的文件哈希值，检测系统分区文件是否被篡改或注入恶意代码 |
| **进程注入检测** | 扫描 Zygote、系统服务、应用进程中是否存在 dex 注入、so hook、ptrace 注入等可疑操作 |
| **模块脚本审计** | 静态分析 Magisk/KernelSU 模块的脚本文件，检测危险命令、文件替换、权限提升等恶意行为 |
| **端口/服务扫描** | 扫描本地开放的端口和运行的后台服务，识别远控工具留下的后门 |
| **流量指纹识别** | 通过 DPI 深度包检测识别远控协议（如 TeamViewer、向日葵、RAT 工具等）的流量特征 |
| **密码强度评估** | 使用 zxcvbn 算法评估密码强度，检测弱密码、常见密码、键盘模式密码 |
| **泄露密码比对** | 使用 k-匿名性（k-Anonymity）技术对接 Have I Been Pwned，密码哈希只发送前 5 位，保护隐私 |

### ⚠️ 风险评估报告

- 每个应用独立安全评分（0-100 分），分数越低越危险
- 风险等级标注：安全 / 低风险 / 中风险 / 高风险，一眼看懂
- 显示每个云端引擎的检测结果（例如「卡巴斯基：安全」「Bitdefender：检测到木马」）
- 详细风险说明和处理建议，告诉你「为什么危险」以及「该怎么办」
- 一键跳转到 VirusTotal / Hybrid Analysis 查看完整检测报告
- 一键卸载/冻结危险应用，发现问题立即解决，不留隐患

### 🔒 隐私保护承诺

- ✅ **不上传完整 APK**：只上传哈希值（指纹），你的应用文件永远不会离开设备
- ✅ **匿名检测**：不需要注册账号，不需要提供任何个人信息
- ✅ **开源透明**：所有检测逻辑完全开源，你可以自行审查代码
- ✅ **数据不保留**：我们不在服务器上存储任何检测记录（云端服务商的隐私政策请参考其各自官网）

## 🤝 常见问题 FAQ

### Q: Huli 支持哪些 Root 方案？
A: 目前支持 Magisk、KernelSU 和 APatch 三种主流 Root 方案。只要你的设备能正常获取 Root 权限，Huli 就能正常工作。

### Q: 病毒检测需要联网吗？
A: 病毒检测采用云端扫描模式，需要联网以查询 VirusTotal、Hybrid Analysis 等云端服务。但请放心，我们**只上传应用的哈希值（指纹）**，不会上传完整的 APK 文件，你的隐私完全受到保护。如果你需要纯离线检测，可以在设置中关闭云端扫描，使用本地特征库模式。

### Q: 会有 iOS 版本吗？
A: 短期内不会考虑。Huli 专注于 Android 平台，毕竟 iOS 的封闭生态和 Root 文化与 Android 完全不同。

### Q: 项目开源吗？
A: 是的！Huli 是一个完全开源的项目，源代码托管在 GitHub 上。欢迎 Star、Fork，也欢迎提交 PR 一起完善这个项目。

### Q: 为什么叫 Huli（狐狸）？
A: 狐狸在东方文化中象征机智、敏捷和灵性。我们希望这款工具能像狐狸一样，敏锐地发现设备中的问题，灵动地响应用户的操作。而且「狐狸」和「Root」都有一个共同点 —— 都是为了更自由地掌控自己的领地 🦊
